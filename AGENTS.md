# Personal Neovim Setup

- Push this repository regularly after major feature changes.
- Small minor edits do not need to be pushed immediately.
- Every project-owned non-test function must document whether it was vibe-coded and whether it has been reviewed.
- When a function is created or changed in Vibing Mode, set its docstring provenance to `Provenance: vibed=true, reviewed=false.` Keep it unreviewed until Kyle reviews it.
- Tests and external systems not owned by this project do not require provenance markers.
